# Практическое занятие №2 — задание 3

Проект содержит базовую модель наземной станции `GroundStation` и окно Qt Widgets. Станция подключает один БПЛА, принимает значения высоты, хранит историю текущего подключения и рассчитывает среднюю высоту. При отключении история очищается, как в примере задания.

Файлы `ground_station.h` и `ground_station.cpp` содержат класс и его реализацию. `main_window.h` и `main_window.cpp` отвечают за интерфейс. Проверки поведения находятся в `tests/`. Вариант 2 («Параметры миссии») добавляет пять параметров в `QMap<QString, double>`: `target_altitude`, `max_speed`, `geofence_radius`, `return_battery` и `mission_timeout`.

Вариант 3 («Перегрузка вывода состояния») добавляет `operator<<` для `QDebug`. Команда `qDebug() << station` выводит название станции, имя БПЛА, признак подключения и число записей; `print_status()` использует этот оператор и дополнительно выводит среднюю высоту и параметры миссии.

Например, для подключённого БПЛА с тремя записями краткий вывод выглядит так: `GroundStation(name="База-1", drone="Survey-01", connected=true, records=3)`. Этот оператор меняет только способ вывода состояния, а не правила подключения или приёма высоты.

Высота и скорость не могут быть отрицательными, радиус геозоны и время миссии должны быть больше нуля, заряд для возврата должен лежать в диапазоне 0–100%. Для времени миссии выбран положительный предел в секундах: документ не задаёт отдельной проверки для него. Недопустимое значение не заменяет ранее сохранённое. Параметры принадлежат станции и сохраняются после отключения БПЛА, но сбрасываются при закрытии программы. В окне введите значения на вкладке «Параметры миссии» и нажмите «Сохранить параметры миссии».

Откройте `CMakeLists.txt` в Qt Creator и выберите комплект Qt 6 с MinGW. Ниже приведён пример команд для компьютера, на котором создавался проект; при другой установке Qt пути будут отличаться.

Zed использует `clangd` для подсветки ошибок C++. После настройки CMake файл `build/compile_commands.json` сообщает ему, где находятся заголовки Qt, включая `QString`. Если Zed уже открыт, перезапустите языковой сервер командой `editor: restart language server` после настройки проекта.

```powershell
$env:Path = 'D:\QT\Tools\mingw1310_64\bin;D:\QT\6.12.0\mingw_64\bin;' + $env:Path
& 'D:\QT\Tools\CMake_64\bin\cmake.exe' -S . -B build -G Ninja '-DCMAKE_MAKE_PROGRAM=D:/QT/Tools/Ninja/ninja.exe' '-DCMAKE_CXX_COMPILER=D:/QT/Tools/mingw1310_64/bin/g++.exe' '-DCMAKE_PREFIX_PATH=D:/QT/6.12.0/mingw_64'
& 'D:\QT\Tools\CMake_64\bin\cmake.exe' --build build
& 'D:\QT\Tools\CMake_64\bin\ctest.exe' --test-dir build --output-on-failure
& '.\build\ground_station_app.exe'
```

После запуска переключитесь на вкладку «Параметры миссии», чтобы ввести и сохранить значения. Вкладка «Станция» содержит подключение БПЛА и историю высоты.
